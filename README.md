# Portfolio – Foundation Analysis Landing Page

A professional landing page for the **Foundation Analysis – Human Design Reading**, designed and developed as part of my web development portfolio.  
This project demonstrates clean **HTML5 + CSS3**, responsive design, accessibility, and SEO best practices.

---

## 🚀 Features

- **Responsive Design** – works seamlessly across desktop, tablet, and mobile.  
- **Clean Code** – semantic HTML5 structure and maintainable CSS.  
- **SEO Optimized** – meta tags, structured data (JSON-LD), and Open Graph.  
- **User-Centered UX** – clear CTAs, trust badges, and FAQ section.  
- **Modern UI** – gradient buttons, hover animations, sticky CTA for mobile.  

---

## 🛠️ Technologies Used

- **HTML5** (semantic structure)  
- **CSS3** (variables, grid, responsive layout, animations)  
- **Schema.org JSON-LD** for structured SEO  
- **Open Graph / Twitter Cards** for social media sharing
